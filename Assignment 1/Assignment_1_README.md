# Lab Assignment No 1 : Recap of Python and Handling and GeoVisualisation of Urban Data

This is a Repository that includes the material and labs required for Assignment No. 1 of the module GG4257 - Urban Analytics: A Toolkit for Sustainable Urban Development at the University of St Andrews, SGSD. 2024.

## Consider

* The /data folder has not been included. Follow the instructions provided in the CoverPage notebook.
* You must install the `ua.yml` environmental file to get all the required libraries.

## Data and Reproducibility

Most datasets used in this assignment are included in the repository. However, the extracted traffic-count dataset, dft_traffic_counts_raw_counts.csv cannot be stored directly on GitHub because it exceeds the 100 MB file limit.

Download the large dataset: [https://drive.google.com/file/d/1Hr380wOfl1gFxXfEUGHMOaa2_kl4e89B/view?usp=drive_link]

To reproduce the analysis:

1. Download the traffic-count dataset using the link above.

2. Ensure the ZIP file is saved at:

Assignment 1/Assignment_1_data/dft_traffic_counts_raw_counts.zip

3. The notebook extracts the ZIP file into:

Assignment 1/Assignment_1_data/traffic_counts_extracted

4. Keep the notebook and data folders in their original  locations.

5. Open Assignment_1.ipynb in JupyterLab and run the notebook cells in order.
